# Quickfetch 0.0.2

Windows Search 的部分功能替代品：即使 Windows Indexer 与 Windows Search 完全关闭，仍可启动应用，并通过 Everything 查找文件。不会自动修改系统搜索服务。

## 新增与改进

- **拼音检索**：中文应用名称支持全拼和首字母，转换结果缓存在内存中；Everything 1.5.0.1387+ 支持文件名原文、全拼和首字母联合查询。
- **全局触屏手势**：顶部左右半区双指下滑、左右屏幕边缘双指内滑，可分别配置快捷键或程序；支持单独 Esc、触屏显示器映射与可选双指右键。顶部下滑从屏幕顶部 6% 内开始，下滑至少高度的 8%。
- **文件模式交互**：窗口缩窄 20%，四列支持触屏拖动调宽并保存；排序列和升降序在重启后恢复。应用→文件保留输入，返回应用清空。
- **文件元数据与图标**：直接显示 Everything 提供的文件夹大小，未提供时显示“—”；文件夹与文档、PDF、图片、影音、压缩包、代码等常见类型使用内存缓存的矢量图标，未知类型使用统一文件图标。修复深色主题路径悬浮提示的白底白字和过长问题。
- **文件拖放**：鼠标拖出或触屏长按约 450ms，向支持文件拖放的应用传递原文件。拖动时显示虚化、可穿透的预览，屏幕顶部整条取消栏与 Esc 均可取消；成功放下后保持收起。
- **Win11 风格文件菜单**：提供打开、打开所在目录、剪切、复制、复制路径、属性；“显示更多选项”调用系统经典 Shell 菜单及可用扩展。
- **界面与输入**：模式切换动画同步更新窗口位置与尺寸，修正抖动；设置改为图标，打开快捷方式文件夹的按钮移入设置；重新打开自动折叠设置。文件键盘新增 `- _ . ( ) [ ] + @ #`，保留整列启动键、光标及系统键盘切换。
- **后台与关闭行为**：点击窗口外收起到托盘，后台和 Win+S 继续工作；外部点击监听仅在窗口可见时启用。增加待机/唤醒和解锁后的输入恢复、本机启动/退出与异常诊断记录；EXE 内嵌图标。

## 下载

- **portable**：包含 .NET 10.0.13 运行时，Windows 11 x64，解压后运行 `Quickfetch.exe`。
- **framework-dependent**：精简版，需要 .NET 10 Desktop Runtime x64。
- 两种压缩包均附 MIT License、贡献者记录、第三方许可和使用文档；使用 `SHA256SUMS.txt` 校验。

文件搜索需要安装并运行 Everything 1.4 或 1.5a。未运行时提示不可用，应用检索仍可使用。程序未签名。

## 验证与限制

完成匹配/拼音、手势边界、排序恢复、增量缓存与图标、Everything 实时检索/排序、Shell 菜单、原生窗口逐帧边界、预览穿透和取消栏边缘命中检查。触屏跨应用拖放及多显示器仍需结合目标应用和设备验证。

全局手势是 Raw Input 并行监听，不能拦截其他应用原本收到的触摸；Quickfetch 文件列表内采用单独的触摸处理。Win11 风格菜单不是 Explorer 现代菜单的完整复刻。后台进程消失的根因尚未确认，新增诊断和恢复处理不代表已证明解决所有退出情况。
