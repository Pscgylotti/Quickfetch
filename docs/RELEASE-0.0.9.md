# Quickfetch 0.0.9

## 主面板和扩展轮盘

- 用鼠标拖动主面板顶部的横条，或在触屏上长按后拖动。松手后会记住位置，下次打开或重启 Quickfetch 时会恢复。双击或双触横条可让面板回到当前显示器中央。
- 扩展轮盘只显示图标。向字符映射、截图或下载的方向滑动并松手即可打开，即使滑出轮盘边缘也有效。拖回圆心松手可取消。

## 快捷开关

- 「电源模式」替换了夜间模式。轻点主按钮切换 Windows 的「节能模式」，右侧箭头可分别为当前供电方式选择最佳能效、平衡或最佳性能。切换节能时可能短暂显示 Windows 设置页。
- Wi-Fi、蓝牙和音量按钮右侧的箭头现在直接打开 Windows 的网络、蓝牙或声音输出面板。关闭系统面板即可回到原来的快捷开关和滚动位置。支持定位的 Windows 11 版本会让系统面板从所点按钮一侧滑入，动画跟随系统设置。

## 下载

Windows x64 用户可选 **portable**（自带 .NET 运行时）或 **framework-dependent**（需要 .NET 10 Desktop Runtime x64）。完整解压后运行 `Quickfetch.exe`。Edge、Chrome 和 Firefox 的下载接管扩展各有独立 ZIP，五个 ZIP 的 SHA-256 校验值见 `SHA256SUMS.txt`。

## English

- Drag the top handle with a mouse, or touch and hold it before dragging. Quickfetch remembers the panel position across launches. Double-click or double-tap the handle to center it on the current display.
- The extension wheel uses icons and accepts a release beyond its edge. Release in the center to cancel.
- The Power mode tile switches Windows Energy saver on or off. Its arrow lets you choose a power mode for the current power source. The Wi-Fi, Bluetooth and volume arrows open the corresponding Windows panels while Quickfetch keeps your place.
