# 字符映射（0.0.5）

主窗口右上角 **扩展功能 → 字符映射**，或主窗口打开时按 **Alt+C**。此快捷键不全局占用其他应用的按键。

在搜索框输入名称、中文关键词、字符本身或 `U+03C0` 一类十六进制编码。下拉分类可筛选科学符号、拉丁与音标、希腊字母、平假名、片假名、Emoji、数字、标点与箭头。例：`积分` / `integral`、`阿尔法` / `alpha`、`lambda`、`hiragana ka`、片假名分类下的 `shi`、`笑脸`。中文关键词覆盖常见科学符号和 CLDR 提供的名称；Unicode 正式英文名称可用于其他字符。

英文或数字输入会同时显示 23 种文字样式：大小写、数学粗体/斜体/粗斜体、花体、哥特体、双线体、无衬线系列、等宽、全角、上下标，以及组合拉丁锐音/重音/长音/分音/抑扬标记。转换是真实 Unicode 文本，不是字体或图片。部分 Unicode 字母没有相应上下标或数字斜体，界面标注缺失数量并保留原文。附加符号不做英语发音或语言翻译。

输入 `Hello world 123` 可点击整段预览一次插入，也可点击下面的单词分别插入。空格、换行和非英文原文在整段转换中保留；逐词按钮只显示前 24 个词，整段转换不受此预览数量限制。输入最多 4,096 个 UTF-16 单元；字符搜索最多展示前 240 项，可用分类或更准确的名称缩小范围。

字符和样式会插入**下方文本框的光标位置**，有选区时替换选区。文本框可以直接编辑；“复制”或 **Ctrl+Enter** 复制全部内容，“清空”仅清空下方文本。组合 Emoji 和肤色/ZWJ 序列整体插入。

键盘沿用主设置的 **使用 Quickfetch 内置键盘** 选项。启用时，点击键盘按钮或触摸文本框会打开独立的亚克力悬浮键盘，平板模式进入字符映射时也会自动打开。拖动顶部把手可用鼠标或触屏移动窗口；键盘不抢占文本框的插入位置，并显示当前编辑目标。支持 Shift 大小写、数字与符号、左右光标、按完整文本元素退格、空格、复制下方文本；右侧 Enter 在搜索框中为“搜索”，在下方文本中为“换行”。点击“收起”、右上角横线或键盘按钮可隐藏悬浮键盘，物理键盘输入会恢复原生文本编辑；Esc 优先收起键盘，再次按下关闭字符映射。内置键盘不提供中文 IME，中文可使用物理输入法或系统键盘。

取消勾选内置键盘时，字符映射继续使用 Windows 系统触摸键盘。关闭字符映射会关闭对应悬浮键盘；键盘位置只保留在当前面板会话中，不另设后台常驻窗口或轮询。

关闭并重新打开时保留本次 Quickfetch 运行期间的搜索和草稿，程序退出后不写入磁盘。复制只写系统剪贴板，不向其他应用自动发送粘贴或键盘事件。

字符数据随程序内置，使用时不联网、不扫描磁盘、不做后台轮询；首次打开时异步解压并缓存供后续搜索。数据基于 [Unicode 17.0](https://www.unicode.org/Public/17.0.0/ucd/UnicodeData.txt)、[Emoji 17.0](https://www.unicode.org/Public/17.0.0/emoji/emoji-test.txt) 及 [CLDR 48](https://github.com/unicode-org/cldr/tree/release-48/common/annotations)，共 43,058 个字符/序列，压缩资源约 537 KiB。Unicode 区间的算法名称（例如 CJK 整块汉字）、控制字符与私用字符未展开。新 Emoji 或少数字形可能因本机字体版本而显示为方框或单色，复制的 Unicode 内容仍完整。

可运行 `python scripts/Build-CharacterData.py` 从固定版本来源重建数据；构建应用和运行搜索本身不需要 Python 或网络。来源哈希见 `Quickfetch.Core/Data/sources.json`，许可见 `THIRD-PARTY-NOTICES.md`。

性能：字符结果采用按行虚拟化，仅渲染可见卡片；索引在加载时一次排序，最近 8 次短查询只缓存结果引用，不建立字形图片缓存。输入合并延迟为 90 ms。本机数据层基准的字符索引保留托管内存由约 21.3 MiB 降到 13.6 MiB，8 次不同查询由约 46 ms 降到 15 ms；这些不是整个应用的内存占用或所有设备的速度保证。
