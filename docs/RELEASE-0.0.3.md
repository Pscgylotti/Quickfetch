# Quickfetch 0.0.3

Windows Search 的部分功能替代品：Windows Indexer 与 Windows Search 完全关闭时，仍可启动应用并通过 Everything 搜索文件。

## 新增与改进

- **Windows 注册应用**：设置中新增默认开启的“包含 Windows 注册应用”，支持 ChatGPT 等没有 `.lnk` 的打包应用。按 AUMID 激活，复用拼音检索与最近使用排序；同一 AUMID 已有快捷方式时优先保留快捷方式。名称与图标缓存，启动复核；之后打开窗口时至多每五分钟复核一次，也可按 F5 手动刷新。
- **文件预览侧栏**：设置中勾选“启用文件预览”后，在文件模式整体右侧显示预览，默认关闭。文本读取开头最多 32 KiB；图片、视频帧限制为 640×480；音乐展示专辑封面、时长、采样率和可用专辑信息；EXE 展示自身图标、产品、公司和版本，未知类型显示基础信息。没有封面时使用默认音乐图标。
- **预览资源控制**：切换选择延迟 180ms 合并请求，切换、隐藏或关闭预览时取消旧请求，仅保留当前预览。文件夹不递归扫描，程序预览不执行目标文件。已有 FFmpeg/FFprobe 时提取视频首个可解码帧、内嵌封面及详细媒体信息，子进程限时四秒；否则使用 Windows 缩略图和属性。
- **触屏滚动条**：透明命中区域扩展为 32 DIP，触摸滑块时独占滚动输入，松手前实时更新列表；修正与列表手势争抢、释放时跳动以及滑块下端圆角被裁切的问题。
- **界面细化**：更紧凑的布局、Fluent 风格图标与切换开关，按钮、结果选择、面板展开和文件菜单增加过渡反馈；调整模式切换动画起始帧时序，遵循 Windows 动画设置。文件夹与文件类型矢量图标重绘。

## 下载

- **portable**：包含 .NET 10.0.13 运行时；Windows 11 x64，解压运行 `Quickfetch.exe`。
- **framework-dependent**：精简版，需安装 .NET 10 Desktop Runtime x64。
- 两种压缩包均包含 MIT License、贡献者记录、第三方许可及使用文档；使用 `SHA256SUMS.txt` 校验。

文件搜索需安装并运行 Everything 1.4 或 1.5a。媒体工具不下载、不捆绑；没有 FFmpeg 时，Windows 缩略图不保证为视频首帧，格式和属性支持取决于本机解码器。程序未签名。

## 验证与已知限制

验证包含匹配/拼音、快捷方式缓存、注册应用身份去重与图标、触摸拖动中的实时滚动、设置保存、文本读取限制、预览取消、图片/视频/音乐预览、EXE 图标与版本信息，以及 Everything 实时检索与排序。

Win11 风格文件菜单不是 Explorer 现代菜单的完整复刻，全局 Raw Input 手势不能拦截其他应用收到的触摸。部分格式或 Shell 扩展无法生成缩略图时会显示默认图标。背景退出排查中，有一次已由 Windows 记录确认为开发版被 `taskkill.exe` 强制结束；这不代表所有历史退出原因均已确认。日常使用请从固定安装目录或解压目录直接启动，避免随开发会话启动。
